# Primitive DB

Консольная база данных на Python с хранением метаданных таблиц в JSON и поддержкой CRUD-операций.

## Установка и запуск

Для установки зависимостей:

```bash
uv sync
```

Для запуска программы:

```bash
uv run database
```

## Управление таблицами

Поддерживаемые типы данных: `int`, `str`, `bool`.

Доступные команды:

- `create_table <имя_таблицы> <столбец:тип> ...` - создать таблицу.
- `list_tables` - вывести список таблиц.
- `drop_table <имя_таблицы>` - удалить таблицу.
- `help` - показать справку.
- `exit` - завершить программу.

При создании таблицы автоматически добавляется столбец `ID:int`.

### Пример использования

```text
Введите команду: create_table books title:str year:int available:bool
Таблица "books" успешно создана со столбцами: ID:int, title:str, year:int, available:bool

Введите команду: list_tables
- books

Введите команду: drop_table books
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "books" успешно удалена

Введите команду: exit
```

## CRUD-операции

Программа поддерживает добавление, просмотр, обновление и удаление записей в таблицах.

Доступные команды:

- `insert into <имя_таблицы> values (<значение1>, ...)` - добавить запись.
- `select from <имя_таблицы>` -вывести все записи.
- `select from <имя_таблицы> where <столбец> = <значение>` - найти записи по условию.
- `update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>` - обновить записи.
- `delete from <имя_таблицы> where <столбец> = <значение>` - удалить записи.
- `info <имя_таблицы>` - показать информацию о таблице.

Все поля при добавлении записи обязательны. Столбец `ID` генерируется автоматически.

Строковые значения указываются в двойных кавычках.

### Пример использования

```text
Введите команду: create_table books title:str year:int available:bool
Таблица "books" успешно создана со столбцами: ID:int, title:str, year:int, available:bool

Введите команду: insert into books values ("Dune", 1965, true)
Запись с ID=1 успешно добавлена в таблицу "books".

Введите команду: select from books
+----+-------+------+-----------+
| ID | title | year | available |
+----+-------+------+-----------+
| 1  | Dune  | 1965 |    True   |
+----+-------+------+-----------+

Введите команду: update books set year = 1966 where title = "Dune"
Запись с ID=1 в таблице "books" успешно обновлена.

Введите команду: delete from books where ID = 1
Вы уверены, что хотите выполнить "удаление записей"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "books".

Введите команду: info books
Таблица: books
Столбцы: ID:int, title:str, year:int, available:bool
Количество записей: 0
```

### Хранение данных

Метаданные таблиц хранятся в файле `db_meta.json`.

Записи каждой таблицы сохраняются в отдельном JSON-файле в директории `data/`. То есть, записи таблицы `books` хранятся в `data/books.json`.

Данные сохраняются между запусками программы. При удалении таблицы соответствующий JSON-файл также удаляется.

## Декораторы и кэширование

Для улучшения работы базы данных реализованы три декоратора:

- `handle_db_errors` - централизованно обрабатывает ошибки `FileNotFoundError`, `KeyError`, `ValueError` и другие исключения.
- `confirm_action(action_name)` - запрашивает подтверждение пользователя перед удалением таблиц и записей.
- `log_time` - измеряет время выполнения операций `insert` и `select` с помощью `time.monotonic()`.

### Кэширование запросов

Функция `create_cacher()` реализует кэширование с помощью замыкания.

Результаты одинаковых запросов `select` сохраняются в памяти и повторно используются без повторного выполнения поиска

После успешных операций `create_table`, `drop_table`, `insert`, `update` и `delete` кэш очищается, чтобы запросы возвращали актуальные данные.
